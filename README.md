# Daniel de Waal Energy Portfolio

Open `index.html` in a modern browser.

Features:
- Interactive 3D Earth
- Drag to rotate
- Mouse wheel to zoom
- Click project markers for project panels
- Project filters
- Responsive mobile layout
- Editable project data embedded in index.html

The prototype uses Three.js from a public CDN, so an internet connection is needed when opening it.

Next step: replace the sample project records with a curated, public-safe project dataset and deploy it to a custom domain.
