# Daniel de Waal | Energy Portfolio

Interactive portfolio of selected renewable-energy and energy-storage projects.

## Files

```text
index.html       # Website and interactive globe
projects.json    # Project database
README.md        # Project documentation
```

## Updating projects

The project data is maintained in Excel.

The website code normally does not need to change.

## Hosting

The site is hosted with GitHub Pages:

https://oandewaal.github.io/energy-portfolio/

Changes committed to `main` are automatically published.

## Technology

HTML · CSS · JavaScript · Three.js · JSON · GitHub Pages
